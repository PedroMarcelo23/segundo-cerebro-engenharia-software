Segundo Cérebro com IA — Engenharia de Software

1. Tema e objetivo

Tema: Engenharia de Software.

Objetivo: Criar um segundo cérebro utilizando Inteligência Artificial para estudar Engenharia de Software, compreender seus fundamentos, conhecer os modelos de desenvolvimento de software e aprender sobre qualidade, métodos ágeis e DevOps com base em fontes confiáveis.

2. Fontes utilizadas

Foram selecionadas três fontes para alimentar o Gemini Notebook:

1. UNIVESP — Engenharia de Software: Aula 01
   
   - Utilizada para estudar os fundamentos, os processos e os modelos de desenvolvimento de software.
   - Fonte educacional de uma universidade pública.

2. SWEBOK v4 — IEEE Computer Society
   
   - Utilizada para conhecer as principais áreas de conhecimento da Engenharia de Software.
   - Publicação de referência da comunidade profissional de Engenharia de Software.

3. Microsoft Learn — Develop with DevOps
   
   - Utilizada para estudar DevOps, Git, GitHub e integração contínua.
   - Documentação técnica oficial da Microsoft.

3. Diretriz de comportamento do notebook

O notebook recebeu a seguinte orientação:

"Comporte-se como um professor especialista em Engenharia de Software. Explique os conceitos de maneira clara, organizada e didática. Utilize as fontes adicionadas ao notebook para responder às perguntas, apresente citações que comprovem as informações e informe quando não encontrar uma resposta nas fontes."

4. Perguntas realizadas e respostas

Pergunta 1

O que é Engenharia de Software e quais são seus principais fundamentos?

Resultado: O notebook explicou que software inclui os programas e sua documentação associada, além de apresentar atributos de qualidade e atividades do ciclo de vida.

Fonte: Aula 01 da UNIVESP.

Pergunta 2

Explique a diferença entre o Modelo Cascata e os Métodos Ágeis. Apresente as vantagens e desvantagens de cada um.

Resultado: O notebook apresentou as diferenças entre os modelos, destacando que o Cascata segue uma abordagem sequencial e preditiva, enquanto os Métodos Ágeis trabalham com ciclos curtos, entregas incrementais e adaptação a mudanças.

Fontes: Materiais adicionados ao notebook, com citações apresentadas na resposta.

- Agilidade e integração contínua.
