01 — Fundamentos da Engenharia de Software

1. O que é Software?

Software não é apenas um programa executado no computador. Ele também inclui toda a documentação associada ao programa.

Exemplos:

- Manual do usuário.
- Ajuda online.
- Documentação do desenvolvimento.
- Especificação de requisitos.

2. O que é Engenharia de Software?

É uma disciplina da engenharia que se preocupa com todos os aspectos da produção de software.

3. Principais objetivos

- Desenvolver programas de qualidade.
- Atender às necessidades dos usuários.
- Facilitar a manutenção.
- Melhorar o desempenho.
- Garantir confiabilidade.

4. Atributos de um bom software

- Funcionalidade: atender ao que o usuário espera.
- Desempenho: funcionar de maneira rápida e eficiente.
- Confiabilidade: apresentar funcionamento estável.
- Usabilidade: ser intuitivo e fácil de utilizar.
- Manutenção: permitir alterações com facilidade.

5. Resumo da aula

A Engenharia de Software utiliza métodos, processos e ferramentas para desenvolver e manter sistemas de software com qualidade.

Objetivo dos estudos

Compreender os fundamentos da Engenharia de Software e aprender como os programas são planejados, desenvolvidos, testados e mantidos.
