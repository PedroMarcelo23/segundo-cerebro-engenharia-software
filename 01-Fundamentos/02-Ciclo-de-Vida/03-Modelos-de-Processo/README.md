03 — Modelos de Processo de Software

1. O que são modelos de processo?

São formas de organizar as atividades necessárias para desenvolver um software.

Eles ajudam a planejar, desenvolver, testar e entregar sistemas.

2. Modelo Cascata (Sequencial)

É um modelo em que as etapas acontecem em uma sequência definida.

Principais etapas:

1. Requisitos.
2. Projeto.
3. Implementação.
4. Testes.
5. Entrega.

Características:

- Etapas organizadas.
- Planejamento sequencial.
- Cada fase possui objetivos definidos.

3. Modelo Incremental

Nesse modelo, o software é desenvolvido e entregue em partes, chamadas incrementos.

Características:

- Desenvolvimento por etapas.
- Entregas frequentes.
- Integração dos componentes.
- Testes durante o desenvolvimento.
- Melhorias contínuas.

4. Reutilização de Software

Consiste em aproveitar componentes e partes de softwares existentes para criar novos sistemas.

Vantagens:

- Aproveitamento de componentes.
- Economia de tempo.
- Redução de trabalho repetitivo.
- Agilidade no desenvolvimento.

5. Comparação dos modelos

Cascata| Incremental
Sequencial| Por partes
Etapas definidas| Entregas frequentes
Planejamento inicial| Evolução gradual

6. Resumo da aula

Os modelos de processo organizam o desenvolvimento de software.

O modelo Cascata trabalha com etapas sequenciais, enquanto o Incremental permite desenvolver e entregar o sistema em partes.

A reutilização permite aproveitar componentes já existentes.

Objetivo dos estudos

Conhecer os diferentes modelos de processo e compreender como eles ajudam na organização do desenvolvimento de software.
