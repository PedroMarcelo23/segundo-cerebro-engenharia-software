02 — Ciclo de Vida do Software

1. O que é o Ciclo de Vida?

O ciclo de vida do software representa as etapas pelas quais um programa passa desde o planejamento até sua evolução e manutenção.

2. Principais atividades

1. Especificação de Requisitos

É a etapa em que são identificadas as necessidades dos usuários e definidas as funcionalidades do sistema.

Exemplos:

- Identificar o que o usuário precisa.
- Definir as funções do sistema.
- Registrar os requisitos.

2. Projeto e Desenvolvimento

É a etapa em que o sistema é planejado e desenvolvido.

Exemplos:

- Planejar a estrutura do software.
- Criar o código.
- Desenvolver as funcionalidades.

3. Validação e Testes

É a etapa em que são realizados testes para verificar se o software funciona corretamente e atende aos requisitos.

Exemplos:

- Identificar erros.
- Testar funcionalidades.
- Verificar os resultados.

4. Evolução Contínua

É a etapa em que o software recebe melhorias, correções e atualizações ao longo do tempo.

Exemplos:

- Corrigir problemas.
- Adicionar funcionalidades.
- Melhorar o desempenho.

3. Por que o Ciclo de Vida é importante?

- Organiza o desenvolvimento.
- Ajuda a identificar problemas.
- Melhora a qualidade.
- Facilita a manutenção.
- Atende às necessidades dos usuários.

4. Resumo da aula

O ciclo de vida do software é composto por quatro atividades principais: especificação de requisitos, projeto e desenvolvimento, validação e testes e evolução contínua.

Essas etapas ajudam a organizar a criação e a manutenção de um software.

Objetivo dos estudos

Compreender como um software é planejado, desenvolvido, testado e melhorado continuamente.
